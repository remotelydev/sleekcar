# Sleek Car

Marketing website for [Sleek Car](https://www.sleek-car.pl) — an auto detailing studio in Turek (PPF, paint correction, coatings).

Built for a friend as a production site: service pages, realizations, reviews, and local SEO.

## Live

https://www.sleek-car.pl

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Prismic CMS

## Local development

```bash
pnpm install
pnpm dev
```

Requires Prismic env vars from `.env.example`. Copy them to `.env.local` before running the app.
